# NEKO-ZUKAI 設計書と設計レビュー

この文書は、いまの NEKO-ZUKAI が「どう動いているか」を通して書き出したもの（前半）と、
そこから見つかった「不自然なところ・直したほうがよい点」（後半）です。
アプリのコードは変えていません。

- 対象: `neko-zukai/index.html`（2026-11-11 時点）、`cat.js`、`breeds/breeds.js`、`firestore.rules`、`README.md`
- 例に出てくる日付はすべて 2026年、毎月の額 30,000円・加算日 25日で計算しています

### 確かめ方と、印の意味

後半の指摘には、どうやって確かめたかの印を付けています。

| 印 | 意味 |
|---|---|
| 【計算で確認】 | `index.html` の計算部分（`compute` など）をそのまま取り出して Node（プログラムを動かす道具）で動かし、出た数字 |
| 【画面で確認】 | 本物の `index.html` をブラウザで開き、Firebase（保存先のサービス）だけ「にせもの」に差し替えて、実際に画面を操作した結果 |

| 【推測】 | 確かめられていないこと（実機の iPhone でしか分からないことなど） |

実機の iPhone・本物の Firebase では試していません。2台同時に操作したときの動きも試していません。

# 前半：設計書

## 1. 目的

**「貯めていく喜び」と「毎日記録する喜び」を感じてもらうこと。**

| だれの | どんな行動を増やしたいか |
|---|---|
| おこづかい（自由に使えるお金）を自分で管理したい人 | ① 毎日、使った額を記録する（使わなかった日も） |
| | ② 1日の目安の中で使う |
| | ③ 期間の終わりにお金を余らせ、それを積み上げていく |

この3つの行動に対して、ネコが反応したり、ごほうびが出たりするのが「報酬（ほうしゅう）の仕組み」です。
後半のレビューは、「この3つをやった人がちゃんと得をするか」「やらない人が得をしていないか」を軸に見ています。

## 2. ことばの説明

| ことば | 意味 |
|---|---|
| 毎月の額 | 毎月自由に使えるお金。設定で決める |
| 加算日 | 毎月の額が足される日（既定 25日）。29〜31日を選ぶと、短い月は月末になる |
| 期間 | 加算日から、次の加算日の前の日まで。例: 10/25〜11/24 |
| 期間の予算 | 繰越 ＋ 毎月の額。その期間に使えるお金の全部 |
| 繰越（くりこし） | 前の期間の残り。余りもマイナスも、そのまま次の期間へ持ちこす |
| 今日の分 | 期間の予算を日数で割った、1日ぶん |
| 今日つかえるお金 | 今日の分 ＋ 前の日までに使わなかった分 − 今日使った額 |
| 貯まった額 | 締めた（終わった）期間の余りの合計。**中身は「今期への繰越」と同じ数字** |
| 段階 | ネコの見た目の5段階。貯まった額 ÷ 毎月の額 で決まる |
| 締める | 加算日が来て、前の期間が終わること |

## 3. お金の流れ

```
毎月の額 ──（加算日に足す）──▶ 期間の予算 ──（日数で割る）──▶ 今日の分
                                  ▲                              │ 使わなかった分は翌日へ
                                  │                              ▼ 使いすぎは翌日から引く
                          繰越（＝貯まった額）◀──（期間の最後の残り）── 今日つかえるお金
```

### 数字の例（すべて【計算で確認】）

**期間の中（1日ごとの動き）** — 10/25 に始めて、予算 30,000円、期間は 10/25〜11/24 の31日。

| 日 | できごと | 今日の分 | 前日までの繰り越し | 今日つかえるお金 |
|---|---|---|---|---|
| 10/25〜27 | 毎日 900円使う | 967円 | | |
| 10/28 朝 | | 967円 | ＋203円（3日ぶんの残り） | 1,170円 |
| 10/28 | 3,000円使う | | | −1,830円（使いすぎ） |
| 10/29 朝 | | 968円 | −1,830円 | −862円 |

- 今日の分が 967円の日と 968円の日があるのは、30,000 ÷ 31 が割り切れないためです。期間の最後の日には、合計がちょうど予算になるように作られています
- **記録がない日は「0円使った日」と同じ扱い**で、その日の分はまるごと翌日に回ります

**期間をまたぐとき** — 前の期間に 20,000円余った場合。

| | 繰越 | 毎月の額 | 期間の予算 | 今日の分 |
|---|---|---|---|---|
| 新しい期間（31日） | 20,000円 | 30,000円 | 50,000円 | 約1,612円 |

- 繰越の 20,000円は、新しい期間の予算に混ざって、31日に薄く広がります（1日あたり約645円ぶん増える）
- 同時に、この 20,000円が「貯まった額」として表示され、ネコの段階を決めます
- マイナスで終わった場合（例: −5,000円）は、次の予算が 25,000円になり、ネコは「ぼさぼさ」になります

**段階のしきい値**（毎月の額 30,000円の場合）

| 段階 | 条件 | 30,000円なら |
|---|---|---|
| 0 ぼさぼさ | 貯まった額がマイナス | 0円未満 |
| 1 ふつう | 0%〜 | 0円〜 |
| 2 毛づくろい | 10%〜 | 3,000円〜 |
| 3 にっこり | 50%〜 | 15,000円〜 |
| 4 液体ネコ | 100%〜 | 30,000円〜 |

## 4. 報酬の仕組み（全体像）

| いつ | 何をすると | 何が起きるか | お金の報酬と関係あるか |
|---|---|---|---|
| **毎日** | 記録する（0円でもよい） | ネコがよろこぶ顔になり、せりふが変わる。連続記録が1日のびる | なし |
| | 目安の中で使う | カレンダーに肉球スタンプ（オレンジ＝目安内） | なし |
| | 使わなかった | 金色のスタンプ | なし |
| | 使いすぎた | グレーのスタンプ、ネコが困り顔 | なし |
| | 今期の残りがマイナス | ネコが悲しい顔 | なし |
| **毎期間**（加算日） | 余らせる | 「貯まった額」が増え、割合に応じてネコの段階が上がる | これが本体 |
| | （加算日のあと初めて開く） | 振り返りの画面（浮いた額・前の期間との差・段階の変化） | |
| | 液体ネコになっている | プレゼントの箱。まだ持っていない品種が1つ手に入る | |
| **長期** | 液体ネコを保ちつづける | 毎期間1つずつ品種が増える（全34種類） | |
| | 連続記録をのばす | 「いちばん長い記録」の数字が増えるだけ | なし |

大事な点:

- **ネコの段階とプレゼントは「期間の終わりの残高」だけで決まります。** 毎日の記録・スタンプ・連続記録は、段階にもプレゼントにも関係しません
- **段階は期間の途中では動きません。** 動くのは加算日だけです（例外は 5章の「設定変更」「記録を直す」）
- ネコの絵は、白・アプリコット（最初から選べる）＋品種34種類。どれも5段階ぶんの絵があります（ウィジェット用の画像も 36種類 × 5段階 ＝ 180枚そろっています）

## 5. 「切り替わり」の一覧

このアプリは、**期間・貯まった額・段階・連続記録・スタンプを保存していません。**
開くたびに、「始めた日」から今日まで、設定の履歴と記録を使って最初から計算し直します。
そのため、過去の記録や設定が変わると、過去の結果もいっしょに変わります。これが下の表の多くの動きのもとです。

| 切り替わり | 何が起きるか |
|---|---|
| **日付が変わる** | 保存されるものは何もない。アプリを開いたとき（または画面に戻ったとき）に計算し直す。今日の分が足され、きのう使わなかった分が繰り越される。きのう記録がなければ連続記録は 0日と表示されるが、あとからきのうの記録を入れればつながる |
| **加算日が来る** | 前の期間が締まる。残り（プラスもマイナスも）が次の期間の繰越になり、毎月の額が足される。「貯まった額」と段階がここで変わる。日割りは新しい予算で最初から数え直す |
| **加算日のあと初めて開く** | 振り返りの画面が1回出る（端末ごとに「どの期間まで見たか」を覚える）。閉じたあと、液体ネコならプレゼントの箱が出る |
| **設定変更：毎月の額** | お金に効くのは次の加算日から（今期の予算は変わらない）。**ただし段階の計算に使う「毎月の額」はその場で変わる**（→ 後半 A-3） |
| **設定変更：加算日** | 画面には「次の加算日から反映」とあるが、実際は**その場で今期の終わりの日が変わる**（→ 後半 B-6） |
| **最初の期間** | 期間の開始日は「今日を含む期間の加算日」までさかのぼる。予算は初期設定の「今期の残り」（空欄なら毎月の額と同じ）。日割りは、最初に記録した日から数える。最初の期間が締まるまで、貯まった額は 0円・段階は「ふつう」 |
| **段階が上がる・下がる** | 加算日にだけ起きる。振り返りの画面で「〜になったにゃ！」「〜になっちゃったにゃ…」と出る。過去の段階は保存していない |
| **プレゼント** | 条件は「締めた期間が1つ以上ある」「いま液体ネコ」「今期まだもらっていない」「未所持の品種がある」。箱を開けずに閉じても、次に画面が描き直されたときにまた出る【画面で確認】。もらった記録はアカウントに付くので、端末が違っても1期間に1回 |
| **毛色・品種の切り替え** | 設定からいつでも変えられる。手に入れた品種だけが選べる。選んだものはアカウントと端末の両方に控える。段階や記録には影響しない |
| **端末をまたぐ** | 記録・設定・品種・プレゼントの受け取りはアカウントに保存され、どの端末でも同じ。振り返りを「見たかどうか」だけは端末ごと。日付は、開いている端末の時計で決まる |
| **記録を直す・消す** | すべて計算し直されるので、過去の期間の残り・貯まった額・段階・スタンプも変わる（→ 後半 B-8） |
| **長く開かない** | 開いたときに、開かなかった日もふくめて計算し直す。記録のない日は「0円使った日」として繰り越される。振り返りは直前の1期間ぶんだけ出る。ウィジェットは期間が終わると「加算日だにゃ／アプリを開いてね」と出る |
| **すべての記録を消して最初から** | 記録・設定に加えて、**手に入れた品種も消える**【画面で確認】（→ 後半 B-9） |

| 場所 | 入っているもの |
|---|---|
| `users/{本人}` | ネコの名前 `catName`／始めた期間の開始日 `start`／最初の期間の予算 `opening`／設定の履歴 `configs`（いつから・毎月の額・加算日）／選んでいる毛色・品種 `catColor`／手に入れた品種 `breeds`／最後にプレゼントをもらった期間 `giftPeriod`／ウィジェット用の秘密の番号 `widgetToken` |

| 名前 | 入っているもの |

期間の区切り、期間ごとの残り、貯まった額、段階、連続記録、スタンプ、今日つかえるお金。

# 後半：不自然なところ・改良すべき点

## 8. まず結論（上位5つ）

1. **記録しない人がいちばん得をする。** 何も記録しないと「全額余った」ことになり、1期間で液体ネコ＋プレゼントが出る（B-1）
2. **「今日つかえるお金」のとおりに使うと、貯まった額がゼロになる。** 毎日の目安と、期間の報酬が逆を向いている（B-2）
3. **貯めたお金の「使いみち」がない。** 貯めたお金で何か買うと「使いすぎ」と言われ、ネコが下がる。液体ネコになったあとは、それ以上貯める理由もない（B-3、B-4）
4. **加算日の設定を変えると、その場で期間が切り替わる。** 今日を加算日にすると、すぐに毎月の額がもう一度足される。翌日に戻しても元に戻らない（B-6）
5. **毎日の記録（連続記録・スタンプ）が、ネコの段階やプレゼントとつながっていない**（B-5）

持ち主の「目的や報酬、切り替わり時の設計が怪しい」という感覚は、1〜3（目的と報酬）と 4（切り替わり）に当たっていました。

## 9. すぐ直せる小さな修正

決まりを変えずに直せるもの、または画面の説明と実際の動きが食い違っているものです。

### A-1. ウィジェットから開いたのに、記録の画面が出ないことがある

- **何が問題か**: 加算日のあと初めてウィジェットから開くと、振り返りの画面が先に出て、閉じても記録の画面が開かない
- **具体例**【画面で確認】: 11/25 に `#add` 付きで開く → 振り返りが出る →「今期もがんばるにゃ」を押す → 何も出ない。振り返りを見たあとの端末なら、同じ開き方で記録の画面がすぐ出る
- **直し方の案**: 振り返り・プレゼントの画面を閉じたときに、記録の画面を開く処理（`maybeOpenAdd`）を呼ぶ
- **おすすめ**: 上の案のとおり。数行で直せます

### A-2. 前の期間の記録を、見ることも直すこともできない

- **何が問題か**: 記録の一覧は「今期の記録」だけ。カレンダーで過去の日を押すと、その日の記録が出るのではなく、新しく記録を入れる画面になる。加算日をすぎてから入れまちがいに気づいても、直せないし消せない
- **具体例**【画面で確認】: 10/20 に「15,000円・まちがい」という記録がある状態で 11/11 に開く → 一覧に出るのは 11月の記録だけ。10/20 を押すと「使ったお金 ¥0」の新しい入力画面になる
- **直し方の案**: (1) カレンダーで日を押したら、その日の記録の一覧と「この日に追加」を出す　(2)「これまでの振り返り」から期間ごとの記録を開けるようにする
- **おすすめ**: (1)。カレンダーがそのまま「過去を見る場所」になり、分かりやすい

### A-3. 毎月の額を変えると、ネコの段階がその場で変わる

- **何が問題か**: 画面には「次の加算日から反映されます」とあるが、段階の計算に使う「毎月の額」だけは保存した瞬間に変わる。額を下げると段階が上がり、プレゼントまで出る。額を上げると（おこづかいが増えたのに）段階が下がる
- **具体例**: 貯まった額 15,000円・毎月 30,000円（にっこり）のとき
  - 毎月の額を 60,000円にする → すぐ「毛づくろい」に下がる【計算で確認】
  - 毎月の額を 15,000円にする → すぐ「液体ネコ」になり、プレゼントの箱が出る【画面で確認】
- **直し方の案**: 段階の計算には「今期に足された額」を使う。そうすれば、段階が変わるのも次の加算日からになる
- **おすすめ**: 上の案のとおり。画面の説明と動きがそろいます。（加算日が来たあとに、新しい額で段階が変わること自体は残ります。それをどうするかは質問 Q7）

### A-4. 振り返りが、別の端末でもう一度出る／何期間も空くと直前のぶんしか出ない

- **何が問題か**: 「見たかどうか」を端末ごとに覚えているため、スマホで見たあとパソコンで開くとまた出る。プレゼントはアカウントごとなので、2台目では「液体ネコになったにゃ！」と出るのに箱は出ない
- **具体例**【画面で確認】: 1台目で振り返りとプレゼントをすませたアカウントを、控えのない端末で開く → 同じ振り返りがもう一度出て、閉じると何も出ない
- **補足**【推測】: iPhone では、ホーム画面に置いたアプリと Safari とで保存領域が別と思われます。ウィジェットは Safari で開くので、同じ iPhone の中でも2回出る可能性があります（実機では未確認）
- **直し方の案**: (1)「見た期間」をアカウント側に保存する（Firestore のルールにも項目を1つ足す必要あり）　(2) いまのまま
- **おすすめ**: (1)。プレゼントと同じ場所に覚えさせれば、食い違いがなくなる

### A-5. 予算がマイナスのとき「今日の分 −¥323」と出る

- **何が問題か**: 繰越が大きなマイナスで、毎月の額を足してもマイナスのとき、今日の分そのものがマイナスになる
- **具体例**【計算で確認】: 繰越 −40,000円・毎月 30,000円 → 予算 −10,000円 → 今日の分 −323円、今日つかえるお金 −323円
- **直し方の案**: この場合は日割りをやめて「今期は −10,000円からのスタートだにゃ」と1行で出す
- **おすすめ**: 上の案。計算は変えず、見せ方だけ変える

### A-6. 文書の古い記述

7章の表のとおり、README に古い説明が残っています（毛色は2種類、「いまここ」、ウィジェットのまとめの中身）。
あわせて、ウィジェット用のまとめに入れている「名前」「連続日数」は使われていないので、入れるのをやめるか、ウィジェットに連続日数を表示するかを決めるとすっきりします。

## 10. 決まりを変える必要があるもの（持ち主の判断が要る）

### B-1. 記録しない人がいちばん得をする　★いちばん大きい

- **何が問題か**: 記録がない日は「0円使った日」と同じ扱いです。そのため、記録を書かないほど「余った」ことになり、貯まった額が増えます。「毎日記録する喜び」という目的と正反対の動きです
- **具体例**:
  - 10/25 に初期設定だけして、1件も記録せずに 11/25 に開く → 「¥30,000 浮いたにゃ！」「液体ネコになったにゃ！」→ プレゼントの箱 → 品種が1つ手に入る【画面で確認】
  - そのまま放置すると、貯まった額は 60,000円、120,000円…と増えつづける【計算で確認】
  - 逆に、正直に毎日 900円ずつ記録して 30,000円を使い切った人は、貯まった額 0円・「ふつう」のまま【計算で確認】
- **直し方の案**:

  | 案 | 内容 | 長所 | 短所 |
  |---|---|---|---|
  | (ア) | 段階アップとプレゼントには「その期間の8割以上の日に記録がある」ことを条件にする | 小さな変更で、記録とごほうびがつながる。B-5 も同時に解決する | 「8割」の線をどこに引くか決める必要がある |
  | (イ) | 記録のない日のぶんは「貯まった額」に数えない | 理屈はいちばん正しい | 計算がややこしくなり、説明しにくい |
  | (ウ) | 決まりは変えず、記録のない日が多いと振り返りで知らせるだけ | 変更が最小 | 得をする構造は残る |

- **おすすめ**: (ア)。「ちゃんと記録して、そのうえで余らせた人」にだけごほうびが出る形になります

### B-2. 「今日つかえるお金」のとおりに使うと、貯まった額がゼロになる

- **何が問題か**: 繰越（＝貯まった額）は、次の期間の予算に混ざって日割りされます。つまり画面のいちばん大きな数字「今日つかえるお金」は、「貯めたお金もふくめて、期間の終わりにちょうど使い切るペース」を示しています。それに従うと、期間の報酬（貯まった額・段階）は失われます
- **具体例**【計算で確認】:
  - 貯まった額 30,000円（液体ネコ）の人が、毎日「今日つかえるお金」ぴったりを使う → 31日すべて「目安内」のスタンプ、連続記録31日 → 加算日に「¥30,000 使いすぎたにゃ…」「ふつうになっちゃったにゃ…」
  - 貯まった額 20,000円の人が、期間の最終日の朝に見る数字は「今日つかえるお金 ¥20,000」。19,000円使っても「目安内」のスタンプ。翌日、貯まった額は 1,000円になり「にっこり」から「ふつう」へ
  - 最終日の朝に「¥20,000」だった数字は、19,000円使った翌日（加算日）には「¥1,033」になる
- **直し方の案**:

  | 案 | 内容 | 長所 | 短所 |
  |---|---|---|---|
  | (ア) | 貯まった額を**別の財布**にする。日割りは「毎月の額」だけで計算し、余りは貯金に入る。使いすぎ（マイナス）は貯金から引く | 「目安を守る＝貯まる」になり、毎日の数字と報酬が同じ向きになる。「貯まった額」という名前どおりになる | 余りを来月の楽しみに使いたい人には不便。貯金から出す方法（B-3）がいっしょに必要 |
  | (イ) | 計算は変えず、「貯まった額を守るなら 1日 ¥○○」をもう1行出す | 変更が小さい | 数字が2つになり、どちらを見ればよいか迷う |
  | (ウ) | 計算は変えず、「貯まった額」を「繰越」と呼び直す。貯めるアプリではなく、使い切るペースを見るアプリと割り切る | 実装はいまのまま正しい | 目的の「貯めていく喜び」をあきらめることになる |

- **おすすめ**: (ア)。目的が「貯めていく喜び」なら、貯めたお金は日々の予算と分けるのが自然です。これは質問 Q1 で、いちばん先に決めてほしい点です

### B-3. 貯めたお金の「使いみち」がなく、使うと怒られる

- **何が問題か**: 貯めたお金でほしい物を買うのは、本来いちばんうれしい瞬間のはずです。いまはそれが「使いすぎ」として扱われ、ネコが下がります。抱えこむほど得、という形になっています
- **具体例**【計算で確認】: 4期間かけて 40,000円貯めた人（液体ネコ）が、40,000円の買い物をして、ふだんの 30,000円もふつうに使う → 振り返りは「¥40,000 使いすぎたにゃ…」、液体ネコから「ふつう」へ
- **直し方の案**:

  | 案 | 内容 | 長所 | 短所 |
  |---|---|---|---|
  | (ア) | 「貯金から使う」という記録の種類を作る。これは使いすぎに数えず、振り返りでは「貯めたお金で買えたにゃ！」と祝う | 貯める→使う の一巡が気持ちよく終わる | 記録の種類が1つ増える |
  | (イ) | 「ほしいもの」と目標額を決められるようにし、達成したらお祝い | 貯める理由がはっきりする | 作るものが多い |
  | (ウ) | いまのまま | 変更なし | 抱えこむほど得、が残る |

- **おすすめ**: まず (ア)。余裕があれば (イ)。あわせて、ネコの段階を「いまの残高」で決めるか「これまでに貯めた合計」で決めるか（質問 Q2）を決める必要があります。後者なら、貯金を使ってもネコは下がりません

### B-4. 液体ネコを保つだけで毎期間プレゼント／100%より上は何も変わらない

- **何が問題か**: プレゼントの条件は「残高が毎月の額以上あること」だけです。一度 100% に届けば、あとは毎期間ぴったり使い切っても（1円も貯めなくても）毎回届きます。また 100% と 300% で見た目もごほうびも同じなので、届いたあとは貯める理由がなくなります
- **具体例**【計算で確認】:
  - 貯まった額 30,000円になったあと、3期間つづけて 30,000円ぴったり使う → ずっと液体ネコ。毎期間プレゼントの条件を満たす
  - 34種類そろうまでの期間（毎月 30,000円の場合）

    | 毎期間に貯める割合 | そろうまで | そのときの貯まった額 |
    |---|---|---|
    | 5%（1,500円） | 53期間（4年5か月） | 79,500円 |
    | 10%（3,000円） | 43期間（3年7か月） | 129,000円 |
    | 20%（6,000円） | 38期間（3年2か月） | 228,000円 |
    | 50%（15,000円） | 35期間（2年11か月） | 525,000円 |
    | 100%（記録ゼロなど） | 34期間（2年10か月） | 1,020,000円 |

    どんなに頑張っても最短 2年10か月。たくさん貯める人と少し貯める人の差は、最初の数か月だけです
- **直し方の案**:

  | 案 | 内容 | 長所 | 短所 |
  |---|---|---|---|
  | (ア) | 条件を「残高」から「その期間の行動」に変える。例: その期間に毎月の額の10%以上を浮かせ、記録も8割以上した | 毎期間「今回がんばったか」で決まる。抱えこみが要らなくなる | 34種類に最短 2年10か月かかるのは同じ |
  | (イ) | 残高の節目ごと（毎月の額の 50%、100%、150%…ごとに1つ） | たくさん貯めるほど早く集まる | 残高を使うと次の節目が遠のく。抱えこみが強まる |
  | (ウ) | (ア)に加えて、連続記録の節目（7日・30日・100日など）でも1つ | 早い時期にごほうびが出て、つづけやすい。記録の報酬にもなる | 後入れで連続記録をつなげられる点（B-5）を決めておく必要がある |

- **おすすめ**: (ウ)。「何年で全部そろうのが気持ちよいか」（質問 Q4）で、節目の数を決められます

### B-5. 毎日の記録（連続記録・スタンプ）が、お金の報酬とつながっていない

- **何が問題か**: 連続記録とスタンプは数字と絵が増えるだけで、段階にもプレゼントにも関係しません。また連続記録は、あとから過去の日を入れればいつでもつながるので、「途切れさせたくない」という気持ちがはたらきにくくなっています
- **具体例**【計算で確認】: 10/25・26・28・29 に記録（27日が抜け）→ 10/30 の時点で連続2日。27日を後から「使わなかった」で入れる → 連続5日
- **補足**: 後入れできること自体は、書き忘れにやさしい良い面でもあります
- **直し方の案**: (ア) B-1(ア)・B-4(ウ) のように、記録した日数や連続記録をごほうびの条件に入れる　(イ) 後入れは「きのうのぶんまで」に限る、または後入れの日は連続記録に数えない　(ウ) いまのまま
- **おすすめ**: (ア)。後入れをどこまで認めるかは質問 Q5

### B-6. 加算日の設定を変えると、その場で期間が切り替わる　★切り替わりでいちばん大きい

- **何が問題か**: 画面には「次の加算日から反映されます」とありますが、実際は保存した日から新しい加算日で数えます。そのため、今期の終わりの日・1日の目安・過去のスタンプがその場で変わり、選んだ日によっては毎月の額がすぐ足されます
- **具体例**【計算で確認】: 期間 10/25〜11/24、11/10 まで毎日 1,000円使った状態で、11/11 に設定を変える
  - **25日 → 10日**: 今期が 12/9 まで（46日）にのびる。「今日つかえるお金」が 9,129円 → 608円に。10/25〜11/10 のスタンプ17個が、すべて「目安内」から「使いすぎ」に変わる
  - **25日 → 12日**: 今期が今日で終わる。「今日つかえるお金」が 28,000円になり、翌日に 30,000円が足される
  - **25日 → 11日（今日）**: その場で期間が締まり、30,000円が足される
  - **今日を加算日にして、翌日に 25日へ戻す**: 11/11 に足された 30,000円は消えず、11/25 にもまた足される（14日間で2回）。同じ日のうちに戻せば、きれいに元に戻る
  - **毎日「今日」を加算日にする**: 5日間で 30,000円が5回足され、貯まった額 148,000円・液体ネコ
  - **加算日の翌日（11/26）に 25日 → 31日**: 今期が 11/25〜11/29 の5日間になり、11/30 にまた 30,000円
- **直し方の案**:

  | 案 | 内容 | 長所 | 短所 |
  |---|---|---|---|
  | (ア) | 加算日の変更は、画面の説明どおり「いまの期間が終わってから」有効にする | 今期の数字やスタンプが変わらない。まちがえても次の加算日までに戻せる | 切り替わりの期間が短くなる（または長くなる）。そのときの額をどうするか決める必要がある（質問 Q6） |
  | (イ) | いまの動きのまま、保存の前に「今期は○月○日までになります。よいですか？」と確かめる | 変更が小さい | 過去のスタンプが変わる、すぐ足される、は残る |

- **おすすめ**: (ア)。毎月の額の変更（A-3）とあわせて、「設定は次の加算日から」という1つの決まりにそろえるのが分かりやすい

### B-7. 最初の期間の余りが、そのまま「貯まった額」になる

- **何が問題か**: 初期設定の「今期の残り」は、空欄だと毎月の額と同じになります。加算日の直前に始めると、数日で大きく「貯めた」ことになります。また、手持ちの全財産を入れると、最初から液体ネコが続きます
- **具体例**【計算で確認】:
  - 11/20 に開始（加算日25日）、今期の残りは空欄（＝30,000円）、5日間で 5,000円使う → 11/25 に貯まった額 25,000円・「にっこり」
  - 今期の残りに 200,000円と入れる → 11/25 に貯まった額 200,000円・液体ネコ（以後、毎期間プレゼント）
- **直し方の案**: (ア) 空欄のときの初期値を「毎月の額 × 残り日数 ÷ 期間の日数」にする　(イ) 最初の期間は「ならし期間」として、余りは繰り越すが、段階アップとプレゼントの対象にしない　(ウ) いまのまま（説明文で注意するだけ）
- **おすすめ**: (ア)＋(イ)。B-2(ア) で貯金を別の財布にするなら、(イ) は「最初の期間の余りは貯金に入れない」と言いかえられます

### B-8. 過去の記録を直すと過去の結果が変わる。プレゼントは増えるが減らない

- **何が問題か**: すべて毎回計算し直すので、締めた期間の記録を変えると、貯まった額と段階が期間の途中でも変わります。それで液体ネコになればプレゼントが出ます。一方、もらったプレゼントは、あとで条件を満たさなくなっても取り消されません。また、開かなかった期間のプレゼントは届きません
- **具体例**:
  - 前の期間の 15,000円の記録を消す → 貯まった額 15,000円 → 30,000円、期間の途中で「にっこり」→ 液体ネコ【計算で確認】
  - 前の期間に 20,000円の記録をあとから足す → 貯まった額 −5,000円、「ぼさぼさ」に【計算で確認】
  - 4期間ずっと液体ネコの状態で、一度も開かずに5期目に開く → プレゼントは1つだけ【画面で確認】
  - 最初の日より前の日をあとから入れると、日割りの数え始めが変わり、ほかの日のスタンプも変わる（10/26 の「目安内」が「使いすぎ」に）【計算で確認】
- **直し方の案**:

  | 案 | 内容 | 長所 | 短所 |
  |---|---|---|---|
  | (ア) | 締めた期間の結果（残り・段階・プレゼントの有無）を、締めたときに保存する。あとから記録を直したら、差額は今期の繰越に反映する | 過去の振り返りが変わらない。開かなかった期間のぶんも判定できる | 保存するデータが増え、作りが少し複雑になる |
  | (イ) | 計算し直しはいまのまま。プレゼントだけ「締めた期間ごとに1回ずつ判定し、未受け取りぶんをまとめて渡す」 | 変更が小さい。正直に直した人が損をしない | 記録を消してプレゼントをもらうことは、できるまま |

- **おすすめ**: (イ)。自分ひとりで使う道具なので、ずるを防ぐより「直したらちゃんと合う」ほうが大事だと考えます。B-4(ア) にすれば、判定は期間ごとの行動になるので自然にこの形になります

### B-9. 「すべての記録を消して最初から」で、集めた品種も消える

- **何が問題か**: 何年もかけて集める品種が、やり直しでいっしょに消えます。確認の文には品種のことが書かれていません
- **具体例**【画面で確認】: 品種を2つ持った状態で「すべての記録を消して最初から」→ アカウントの設定がまるごと消え、初期設定の画面に戻る
- **直し方の案**: (ア) 品種と選んでいる毛色は残し、記録と金額の設定だけ消す　(イ) いまのまま、確認の文に「集めたネコも消えます」と足す
- **おすすめ**: (ア)

### B-10. 期間の途中は、がんばってもネコが変わらない

- **何が問題か**: 段階は加算日にしか動かないので、最長1か月、節約の手ごたえが見た目に出ません。「今期はいくら貯まりそうか」も画面にありません
- **具体例**【計算で確認】: 10/25 から毎日記録して節約しても、11/24 まで貯まった額は 0円・「ふつう」のまま
- **直し方の案**: (ア)「貯まった額」のカードに「今期ここまでに浮いた額 ¥○○。このままなら加算日に『毛づくろい』になるにゃ」と見込みを出す　(イ) 段階そのものを、今期の見込みで毎日動かす
- **おすすめ**: (ア)。段階が毎日上下すると落ち着かないので、見込みを言葉で出すだけにする。B-2(ア) にした場合、「今期ここまでに浮いた額」は「今日つかえるお金」の残りそのものなので、すぐ出せます

### 確かめて、問題がなかったこと

- しきい値（10%・50%・100%）の端数: 毎月の額 1円〜300,000円のすべてで、「あと ¥○○ で次の段階」の表示と実際の判定がずれないことを確かめた【計算で確認】
- ウィジェットの「今日つかえるお金」は、アプリと同じ式になっている【コードで確認】
- 同じ日のうちに設定を変えて戻した場合は、履歴がきれいに元に戻る【計算で確認】
- プレゼントは、箱を開けずに閉じてもなくならない【画面で確認】

| 1 | **貯金は別の財布。** 毎日の目安は「毎月の額」だけを日割りする。次の期間は、いつも毎月の額ちょうどから始まる（マイナスを持ちこさない） | B-2 |
| 2 | **貯まった額 ＝ 締めた期間までの貯金 ＋ 今期ここまでに浮いた額。** 毎日動く。使わなければ増え、使いすぎるとその場で減る（＝貯金から出す）。加算日には、今期の浮きが貯金に入るだけ | B-2、B-10 |
| 3 | 貯金が足りない使いすぎは、**貯金をマイナスにする**（ネコは「ぼさぼさ」）。次に浮いた分から自然に返す | B-2 |
| 4 | **記録した日（0円でも）の分だけ、貯まった額に数える。** 後入れは1週間前まで。1週間すぎた日の分は数えない | B-1、B-5 |
| 5 | ネコの段階は、いまの貯まった額で決める。**上がるのは毎日**（月末に向けて上がっていく）。**下がるのは期間の切り替わり（加算日）だけ**。期間の途中で貯まった額が減っても、ネコはその期間のあいだ下がらない | B-10 |
| 6 | 段階は円ではなく「**毎月の額の何%ぶん貯めたか**」を、貯めた時点の額で数えて足していく。毎月の額を変えても段階は変わらない | A-3 |
| 7 | 貯金を引き出せるのは、先に登録した「**ほしいもの**」に届いたときだけ。ほしいものは**複数**登録でき、**優先順位**を付ける。貯金は上から順に割り当て、届いたものだけ買える。買うとお祝いが出て、貯金が減る。ネコは次の加算日に、残った貯金に合わせた段階になる | B-3 |
| 8 | プレゼントは**1期間に最大1つ**。条件は「液体ネコで期間を終える」＋「その期間の8割以上の日に記録がある」。段階は期間の途中で下がらないので、液体ネコのときにほしいものを買っても、その期間のプレゼントはもらえる。品種は今後も増やせる | B-1、B-4 |
| 9 | 加算日の変更は、**いまの期間が終わってから**効く。切り替わりの1回だけ、日数に合わせた額を足す（1日あたりの額が変わらないように） | B-6 |
| 10 | 初期設定の「今期の残り」の入力をなくす。最初の期間は「毎月の額 × 残り日数 ÷ 期間の日数」。余りはふつうに貯金に入る | B-7 |
| 11 | 過去の記録を直したら、過去の数字も正しい数字に直る（いまと同じ） | B-8 |
| 12 | 「すべての記録を消して最初から」は、ふだん使わないのでなくす方向。残す場合も、集めた品種は消さない | B-9 |

## 13. 数字の例（毎月 30,000円、期間 11/25〜12/24 の30日、今日の分は 1,000円）

期間の初めの貯金は 10,000円（毎月の額の 33%ぶん＝「毛づくろい」）とします。

| 日 | できごと | その日の浮き | 今期の浮き | 貯まった額 | 段階 |
|---|---|---|---|---|---|
| 11/25 | 600円使って記録 | ＋400 | 400 | 10,400 | 毛づくろい |
| 11/26 | 記録なし | （保留） | 400 | 10,400 | 毛づくろい |
| 11/27 | 「使わなかった」を記録 | ＋1,000 | 1,400 | 11,400 | 毛づくろい |
| 11/28 | 11/26 のぶんを後入れ（300円） | ＋700（11/26 の分） | 2,100 | 12,100 | 毛づくろい |
| 11/28 | 5,000円使って記録 | −4,000 | −1,900 | 8,100 | 毛づくろい |
| … | 12/24 まで毎日 800円で記録 | ＋200 × 26日 | 3,300 | 13,300 | 毛づくろい |
| 12/25 | 加算日。今期の浮き 3,300円が貯金に入る | | 0 | 13,300 | 毛づくろい |

- 12/25 からの今日の分は、貯金に関係なく 30,000 ÷ 31日 ≒ 967円
- 11/28 のように使いすぎると、その場で貯まった額が減る。期間の終わりに浮きがマイナスなら、その分が貯金から引かれる
- 貯まった額が 15,000円（50%）をこえた日に「にっこり」、30,000円（100%）をこえた日に「液体ネコ」になる
- 11/28 のように貯まった額が減っても、ネコが下がるのは次の加算日。加算日に、そのときの貯まった額で段階を決め直す

**ほしいものを買う例**: 貯金 30,000円（液体ネコ）で、30,000円のほしいものを買う
→ 貯金は 0円になり、お祝いが出る。ネコはその期間の終わりまで液体ネコのまま（記録が8割以上ならプレゼントももらえる）。
次の加算日に、そのときの貯まった額（たとえば 2,000円）で決め直して「ふつう」になり、また育てていく。

**ほしいものが複数ある例**: 貯金 25,000円、1番 20,000円、2番 10,000円
→ 1番は「届いた」（買える）、2番は「5,000 / 10,000円」。先に2番を買いたいときは、順番を入れかえる。

**加算日を変える例**: 25日 → 10日に変える（11/11 に設定）
→ 11/24 まではいまのまま。11/25〜12/9 の15日間は 15,000円（1日 1,000円のまま）。12/10 からは 30,000円。

**最初の期間の例**: 11/20 に始める（加算日25日、期間は31日）
→ 11/20〜11/24 の5日間、予算は 30,000 × 5 ÷ 31 ≒ 4,838円（1日 約967円）。

## 14. 決まりから出てくること（知っておいてほしい点）

- **書き忘れた日の分は「今日つかえるお金」にも入りません。** 貯まった額と同じ数字を使うためです。1週間以内に後入れすれば入ります。1週間すぎると、その日の分はアプリの中では数えられなくなります
- **数字が2つになります。**「貯金（円）」と「段階を決める%」です。ふだんは同じ意味で、ずれるのは毎月の額を変えたあとだけです
- **貯まった額の数字は毎日上下しますが、ネコが下がるのは加算日だけです。** 期間の途中で大きく使いすぎても、ネコはその期間の終わりまでそのままです（液体ネコなら、記録が8割以上あればプレゼントももらえます）。「ぼさぼさ」になるのも加算日です
- **連続記録**は、1週間すぎた抜けはつながらなくなります
- **過去のスタンプ**は、日割りに貯金が混ざらなくなるので、いまより「使いすぎ」が増えることがあります
